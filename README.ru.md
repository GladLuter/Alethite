# Claude-CacheGuard

Мод для Claude Code: долгие чаты-«работники» становятся дешевле и не теряют память.

## Зачем

Аудит транскриптов владельца (май–октябрь 2026, по ценам API) показал, куда уходят деньги:
- 89% — на повторную отправку уже существующего контекста (запись в кэш и чтение из него);
- 32% — первое сообщение после паузы больше часа в большом чате, когда часовой кэш истёк и весь контекст записывается заново по двойной цене.

Дорого не то, что пишется, а возвращение к большому простаивающему чату.

## Что делает

**Сторож кэша.**
- В строке состояния — размер контекста и минуты до истечения кэша.
- При возвращении к большому чату после паузы полоса над полем ввода показывает, сколько стоит отправка туда сейчас.
- Кнопка **«Новый работник»** начинает чистый чат: механическая передача дел (без вызовов модели) плюс уже набранное сообщение.

**Короткая память.** Встроенная автопамять Claude Code. Мод добавляет:
- одно короткое правило в системный промпт: решения записывать сразу, понятую ошибку сохранять уроком, проверять память, прежде чем предлагать;
- уведомление о каждом сохранённом факте.

**Долгая память.** Все прошлые разговоры всех проектов, включая субагентов, в локальном индексе SQLite (FTS5) с векторами локальной модели Ollama.
- Работник вызывает `recall` (гибридный поиск по словам и по смыслу) и `recall_more` (прочитать вокруг находки).
- Секреты скрываются до индексации.
- Попавшее в индекс никогда не теряется: перестройка и переписанные транскрипты только добавляют.

**Два компьютера** (этап 2). Общая папка на сетевом диске переносит индекс, векторы и факты памяти.
- Каждый компьютер пишет только свои пронумерованные пачки; слияние механическое и повторяемое.
- Без папки всё работает локально.

**Сжатие памяти** (этап 3). То, что мод даёт модели (выдача поиска, цитаты передачи дел), сжимается механически. Четыре уровня, по умолчанию `ultra`; код, пути и отрицания не трогаются.
- `/cg-stats` измеряет, сколько памяти в контексте.

**Уроки** (этап 4). Понятая ошибка сохраняется уроком в индексе, а не в автопамяти, которая грузится в каждый запрос.
- Мод возвращает урок механически, только к месту: к сообщению владельца, близкому по смыслу (скрытый контекст, не больше 2, каждый раз в чат), и как одну остановку перед командой с его триггером.
- Нет уроков или не подошёл — ноль токенов. `/cg-health` показывает, во что они обходятся.

**Поиск по следам ошибки** (этап 4). Ошибки инструментов попадают в индекс; `recall` ищет сразу несколько формулировок (текст ошибки, действие, причина).

**Фоновая задача** (этап 4, Windows). Задача Планировщика заданий без открытого чата обновляет индекс, векторы (от сети) и синхронизацию.

**Шифрование** (этап 5, Windows, по желанию). Индекс на диске и всё, что компьютер кладёт в папку синхронизации, шифруются. Ключ лежит в `settings.json` под защитой Windows.
- Включает его `/cg-encrypt on`. Код восстановления показывается один раз, в окне, и место ему в менеджере паролей. Второй компьютер присоединяется командой `join`.
- Способы выбираются в `settings.json`, отдельно для индекса (`indexCipher`) и для папки синхронизации (`shareCipher`). Без настройки остаётся SQLCipher.
  - Индекс: SQLCipher (нужен пакет `sqlcipher3`) или EFS, шифрование файлов самой Windows (нужны Windows Pro и диск NTFS, пакеты не нужны).
  - Папка синхронизации: SQLCipher или AES-GCM, он встроен в Windows, пакеты не нужны.
- Smart App Control может не дать загрузить `sqlcipher3`, поэтому под ним годятся только EFS и AES-GCM. Пакет `cryptography` больше не нужен.
- С EFS копия индекса на флешку или в сеть получается открытой, а файлы открываются только под той же учётной записью Windows.
- Открытыми остаются транскрипты Claude Code, файлы автопамяти проектов и передачи дел.
- Пока вы не набрали `/cg-encrypt on`, у вас ничего не меняется.

**Языки.** Английский (по умолчанию), русский, украинский: интерфейс, тексты для модели и передача дел.

## Команды

| команда | что делает |
|---|---|
| `/cg-health` | проверяет мод, индекс, векторы, память, синхронизацию и сжатие |
| `/cg-band [off]` | показать полосу сейчас или вернуть пороги |
| `/cg-index [rebuild]` | обновить индекс (rebuild: перечитать всё и добавить недостающее) |
| `/cg-sync [skip <компьютер> <N>]` | синхронизировать с другими компьютерами сейчас |
| `/cg-stats [дней]` | замер расходов в Obsidian |
| `/cg-lessons [forget <pos>]` | уроки этого проекта; удалить урок |
| `/cg-job [on [минут] \| off]` | фоновая задача (Windows): включить, выключить, состояние |
| `/cg-encrypt [on \| join \| off \| status]` | шифрование индекса и папки синхронизации (Windows): включить, присоединить второй компьютер, выключить, состояние |
| `/cg-index-dir [папка]` | перенести индекс в другую папку на локальном диске (Windows), без папки откроется окно выбора |

## Настройки (файл `settings.json`)

Файл `%USERPROFILE%\.claude\cacheguard\settings.json` свой на каждом компьютере и остаётся в этой папке, даже когда индекс переехал. Мод создаёт его при первом запуске со всеми текущими значениями, остаётся открыть и поправить. Мод читает файл при каждой загрузке, и значения из него главнее `/config`. После правки наберите `/reload-plugins`. Обратные слеши в JSON удваиваются.

| ключ | что задаёт | по умолчанию |
|---|---|---|
| `language` | язык | `"en"` (ещё `"ru"`, `"uk"`) |
| `compression` | сжатие памяти | `"ultra"` (ещё `"off"`, `"lite"`, `"full"`) |
| `syncDir` | папка синхронизации | `""` (пусто: без синхронизации) |
| `bandMinTokens` | порог полосы: размер чата, токенов | `100000` |
| `bandIdleMinutes` | порог полосы: простой, минут | `55` |
| `showLimits` | строка лимитов в полосе | `true` |
| `python` | команда Python | `"python"` |
| `embedModel` | модель эмбеддингов Ollama | `"embeddinggemma"` |
| `lessons` | возвращать уроки к сообщениям и командам | `true` |
| `lessonsMinScore` | насколько близким должно быть сообщение (0–1) | `0.45` |
| `indexCipher` | чем шифруется индекс (при `/cg-encrypt on` мод записывает сам) | `"sqlcipher"` (ещё `"efs"`) |
| `shareCipher` | чем шифруется папка синхронизации (при `/cg-encrypt on` мод записывает сам). `"cryptography"` значит AES-GCM из Windows, пакет не нужен | `"sqlcipher"` (ещё `"cryptography"`) |
| `indexDir` | папка индекса (пишет `/cg-index-dir`, руками не править) | нет ключа (индекс в стандартной папке) |

В файле можно оставить только те ключи, которые вы меняете. Например:

```json
{
  "language": "ru",
  "syncDir": "Z:\\cacheguard"
}
```

## Что нужно

- Десктопное приложение Claude Code (движок 2.1.295 или новее);
- Python 3.8+ с numpy;
- Ollama для поиска по смыслу (по желанию);
- пакет `sqlcipher3` для способов шифрования SQLCipher (по желанию, только Windows);
- Windows Pro и диск NTFS для способа EFS (по желанию);
- git.

## Приватность

- Индекс и векторы содержат личную переписку. Они остаются на компьютерах владельца и в его сетевой папке: никогда не попадают в этот репозиторий и никуда больше не уходят.
- Единственные сетевые обращения — к локальной Ollama и к общей папке.
