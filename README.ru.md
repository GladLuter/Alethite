## 💸 Зачем

Я проверил собственные транскрипты Claude Code (май-октябрь 2026, по ценам API), чтобы понять, куда уходят деньги.

- **89%** ушло на повторную отправку контекста, который уже есть (запись в кэш и чтение из него).
- **32%** ушло на первое сообщение после паузы больше часа в большом чате. Часовой кэш истёк, и весь контекст записался заново по двойной цене.

Деньги уходят на возвращение в большой чат, который долго простоял. Alethite показывает цену до отправки и хранит память прошлых чатов, так что новый чат начинает не с нуля.

## ✨ Что вы получаете

| Функция | Что делает | Команда |
|---|---|---|
| 🛡️ **Сторож кэша** | В строке состояния виден размер контекста и минуты до истечения кэша. Над полем ввода всегда стоит одна строка: размер чата, кэш, цена отправки сюда и сколько сэкономили передачи дел. Кнопка «Детали» раскрывает её в колонки. | `/al-band` |
| 🆕 **Новый работник** | Кнопка начинает чистый чат: передача дел из старого (без вызовов модели) и сообщение, которое вы уже набрали. Кнопка «После сброса» делает то же, когда сбросится лимит. Она появляется после нажатия на «Новый работник», если какой-то лимит использован на 90% или больше. | кнопки в полосе |
| 📝 **Короткая память** | Одно короткое правило для Claude: решения записывать сразу, понятую ошибку сохранять уроком, перед предложением проверять память. Каждый сохранённый факт показывается уведомлением. | |
| 🔎 **Долгая память** | Все прошлые разговоры всех проектов, включая субагентов, в локальном индексе SQLite с векторами локальной модели Ollama. Claude ищет по ним через `recall`, по словам и по смыслу. Секреты скрываются до индексации. Ничто из попавшего в индекс не теряется. Ошибки инструментов тоже индексируются. | `/al-index` |
| 🎓 **Уроки** | Понятая ошибка сохраняется уроком и возвращается только там, где подходит. Команда с триггером урока один раз останавливается вместе с ним, и на сообщение приходит не больше 2 уроков. Нет подходящего урока, значит ноль токенов. Урок бывает и для всех проектов (`scope: all`). Он приходит коротким напоминанием примерно каждые 20 тыс. токенов чата и стоит этих токенов в каждом проекте. `/al-lessons` такие уроки помечает. | `/al-lessons` |
| 🔄 **Синхронизация компьютеров** | Общая папка на сетевом диске переносит индекс, векторы и факты памяти. Без неё всё работает локально. | `/al-sync` |
| 🗜️ **Сжатие памяти** | То, что плагин отдаёт модели, сжимается механически, на четырёх уровнях. Код, пути и отрицания не трогаются. | `/al-stats` |
| ⏱️ **Фоновая задача** | Задача Планировщика заданий держит индекс, векторы и синхронизацию свежими, даже когда ни один чат не открыт. Только Windows. | `/al-job` |
| 🔐 **Шифрование** | По желанию. Шифрует индекс на диске и всё, что компьютер кладёт в папку синхронизации. Только Windows. | `/al-encrypt` |
| 🌍 **Языки** | Русский, украинский, английский: интерфейс, тексты для модели и передача дел. | |

## 🚀 Быстрый старт

Нужны десктопное приложение Claude Code (движок 2.1.295 или новее), Python 3.8+ с numpy и git. Ollama необязательна, но без неё поиск идёт только по словам. Команды выполняйте в PowerShell.

```powershell
git clone https://github.com/GladLuter/Alethite.git C:\_git\Alethite
```

Потом зарегистрируйте плагин через собственный `claude.exe` десктопного приложения. Первая строка находит его и должна напечатать путь, который кончается на `claude.exe` (если она ничего не печатает, в INSTALL.ru.md есть поиск пошире):

```powershell
$CC = (Get-ChildItem "$env:LOCALAPPDATA\Claude-Data\claude_*\claude-code\*\*\claude.exe", "$env:APPDATA\Claude\claude-code\*\*\claude.exe", "$env:LOCALAPPDATA\Packages\Claude_*\LocalCache\Roaming\Claude\claude-code\*\*\claude.exe" -ErrorAction SilentlyContinue | Sort-Object LastWriteTime | Select-Object -Last 1).FullName; $CC
& $CC plugin marketplace add C:\_git\Alethite
& $CC plugin install alethite@alethite
```

Перезапустите приложение и постройте индекс:

```powershell
python C:\_git\Alethite\plugin\scripts\cg.py index
```

Для проверки наберите `/al-health` в новом чате. Расчёт векторов (в первый раз он идёт несколько часов) и остальные шаги описаны в **[INSTALL.ru.md](INSTALL.ru.md)**.

## ⌨️ Команды

| Команда | Что делает |
|---|---|
| `/al-health` | Проверяет плагин, индекс, векторы, память, синхронизацию и сжатие |
| `/al-band [off]` | Возвращает полосу или прячет её в этом чате (`off`) |
| `/al-index [rebuild]` | Обновляет индекс. `rebuild` перечитывает всё и добавляет недостающее |
| `/al-sync [skip <компьютер> <N>]` | Синхронизирует с другими компьютерами сейчас |
| `/al-stats [days]` | Замеряет стоимость и записывает в Obsidian |
| `/al-lessons [forget <pos>]` | Показывает уроки проекта или удаляет один |
| `/al-job [on [минуты] \| off]` | Фоновая задача (Windows): включить, выключить, состояние |
| `/al-encrypt [on \| join \| off \| status]` | Шифрование индекса и папки синхронизации (Windows) |
| `/al-index-dir [папка]` | Переносит индекс на другой локальный диск (Windows). Без папки её выбирают в окне |

<details>
<summary><b>⚙️ Настройки</b></summary>

<br>

Файл `%USERPROFILE%\.claude\alethite\settings.json` свой на каждом компьютере. Плагин создаёт его при первом запуске со всеми текущими значениями, так что остаётся открыть и поправить. Его значения имеют приоритет над `/config`. После правки наберите `/reload-plugins`. Обратные косые черты в JSON удваиваются.

| Ключ | Что задаёт | По умолчанию |
|---|---|---|
| `language` | Язык | `"en"` (также `"ru"`, `"uk"`) |
| `compression` | Сжатие памяти | `"ultra"` (также `"off"`, `"lite"`, `"full"`) |
| `syncDir` | Папка синхронизации | `""` (пусто: без синхронизации) |
| `bandMinTokens` | Подсветка строки: размер чата, токены | `100000` |
| `bandIdleMinutes` | Подсветка строки: простой, минуты | `55` |
| `showLimits` | Колонка лимитов в «Деталях» | `true` |
| `python` | Команда Python | `"python"` |
| `embedModel` | Модель эмбеддингов Ollama | `"embeddinggemma"` |
| `lessons` | Возвращать уроки к сообщениям и командам | `true` |
| `lessonsMinScore` | Насколько близким должно быть сообщение (0-1) | `0.45` |
| `indexCipher` | Как шифруется индекс (`/al-encrypt on` записывает сам) | `"sqlcipher"` (также `"efs"`) |
| `shareCipher` | Как шифруется папка синхронизации (`/al-encrypt on` записывает сам). `"cryptography"` означает AES-GCM, встроенный в Windows | `"sqlcipher"` (также `"cryptography"`) |
| `indexDir` | Папка индекса (пишет `/al-index-dir`, вручную не править) | нет ключа |
| `projectAliases` | Старые папки, чью память видит и папка проекта: `{"C:\\work\\new": ["C:\\work\\old"]}` | нет ключа |

В файле могут быть только те ключи, которые вы меняете:

```json
{
  "language": "ru",
  "syncDir": "\\\\NAS\\share\\alethite"
}
```

</details>

<details>
<summary><b>🔐 Подробнее о шифровании</b></summary>

<br>

Пока вы не выполнили `/al-encrypt on`, для вас ничего не меняется. Ключ лежит в `settings.json` под защитой Windows. Код восстановления показывается один раз, в окне. Сохраните его в менеджере паролей. Второй компьютер подключается командой `/al-encrypt join`.

У индекса и у папки синхронизации свои шифры:

- Индекс: SQLCipher (нужен пакет `sqlcipher3`) или EFS, шифрование файлов самой Windows (нужны Windows Pro и диск NTFS, пакеты не нужны).
- Папка синхронизации: SQLCipher или AES-GCM, он встроен в Windows, пакеты не нужны.

Smart App Control может отказаться загружать `sqlcipher3`. Тогда работают только EFS и AES-GCM.

При EFS копия индекса на флешке FAT или exFAT или по сети получится нешифрованной, а файлы открываются только под той же учётной записью Windows.

Собственные транскрипты Claude Code, файлы автопамяти каждого проекта и текст передачи дел, который идёт в чат, остаются открытыми. При EFS файлы передачи дел на диске зашифрованы.

Полная инструкция: [INSTALL.ru.md](INSTALL.ru.md).

</details>

## 📋 Требования

- Десктопное приложение Claude Code, движок 2.1.295 или новее
- Python 3.8+ с numpy
- git
- Ollama для поиска по смыслу (необязательно)
- Пакет `sqlcipher3` для шифров SQLCipher (необязательно, только Windows)
- Windows Pro и диск NTFS для шифра EFS (необязательно)

## 🔒 Конфиденциальность

Индекс и векторы хранят ваши разговоры. Они остаются на ваших компьютерах и в вашей сетевой папке. В этом репозитории их нет, и никуда больше они не отправляются. Сетевые обращения идут только к вашей локальной Ollama и к вашей общей папке.
