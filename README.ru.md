# Claude-CacheGuard

Мод для Claude Code: долгие чаты-«работники» становятся дешевле и не теряют память.

## Зачем

Аудит транскриптов владельца (май–октябрь 2026, по ценам API) показал, куда уходят деньги:
- 89% — на повторную отправку уже существующего контекста (запись в кэш и чтение из него);
- 32% — первое сообщение после паузы больше часа в большом чате, когда часовой кэш истёк и весь контекст записывается заново по двойной цене.

Дорого не то, что пишется, а возвращение к большому простаивающему чату.

## Что делает

**Сторож кэша.**
- В строке состояния — размер контекста и минуты до истечения кэша.
- При возвращении к большому чату после паузы полоса над полем ввода показывает, сколько стоит отправка туда сейчас.
- Кнопка **«Новый работник»** начинает чистый чат: механическая передача дел (без вызовов модели) плюс уже набранное сообщение.

**Короткая память.** Встроенная автопамять Claude Code. Мод добавляет:
- одно короткое правило в системный промпт: записывать грабли и решения сразу, проверять память, прежде чем предлагать;
- уведомление о каждом сохранённом факте.

**Долгая память.** Все прошлые разговоры всех проектов, включая субагентов, в локальном индексе SQLite (FTS5) с векторами локальной модели Ollama.
- Работник вызывает `recall` (гибридный поиск по словам и по смыслу) и `recall_more` (прочитать вокруг находки).
- Секреты скрываются до индексации.
- Попавшее в индекс никогда не теряется: перестройка и переписанные транскрипты только добавляют.

**Два компьютера** (этап 2). Общая папка на сетевом диске переносит индекс, векторы и факты памяти.
- Каждый компьютер пишет только свои пронумерованные пачки; слияние механическое и повторяемое.
- Без папки всё работает локально.

**Сжатие памяти** (этап 3). То, что мод даёт модели (выдача поиска, цитаты передачи дел), сжимается механически. Четыре уровня, по умолчанию `ultra`; код, пути и отрицания не трогаются.
- `/cg-stats` измеряет, сколько памяти в контексте.

**Языки.** Английский (по умолчанию), русский, украинский: интерфейс, тексты для модели и передача дел.

## Команды

| команда | что делает |
|---|---|
| `/cg-health` | проверяет мод, индекс, векторы, память, синхронизацию и сжатие |
| `/cg-band [off]` | показать полосу сейчас или вернуть пороги |
| `/cg-index [rebuild]` | обновить индекс (rebuild: перечитать всё и добавить недостающее) |
| `/cg-sync [skip <компьютер> <N>]` | синхронизировать с другими компьютерами сейчас |
| `/cg-stats [дней]` | замер расходов в Obsidian |

## Настройки (файл `settings.json`)

Файл `%USERPROFILE%\.claude\cacheguard\settings.json` свой на каждом компьютере и лежит рядом с индексом. Мод создаёт его при первом запуске со всеми текущими значениями, остаётся открыть и поправить. Мод читает файл при каждой загрузке, и значения из него главнее `/config`. После правки наберите `/reload-plugins`. Обратные слеши в JSON удваиваются.

| ключ | что задаёт | по умолчанию |
|---|---|---|
| `language` | язык | `"en"` (ещё `"ru"`, `"uk"`) |
| `compression` | сжатие памяти | `"ultra"` (ещё `"off"`, `"lite"`, `"full"`) |
| `syncDir` | папка синхронизации | `""` (пусто: без синхронизации) |
| `bandMinTokens` | порог полосы: размер чата, токенов | `100000` |
| `bandIdleMinutes` | порог полосы: простой, минут | `55` |
| `showLimits` | строка лимитов в полосе | `true` |
| `python` | команда Python | `"python"` |
| `embedModel` | модель эмбеддингов Ollama | `"embeddinggemma"` |

В файле можно оставить только те ключи, которые вы меняете. Например:

```json
{
  "language": "ru",
  "syncDir": "Z:\\cacheguard"
}
```

## Что нужно

- Десктопное приложение Claude Code (движок 2.1.295 или новее);
- Python 3.8+ с numpy;
- Ollama для поиска по смыслу (по желанию);
- git.

## Приватность

- Индекс и векторы содержат личную переписку. Они остаются на компьютерах владельца и в его сетевой папке: никогда не попадают в этот репозиторий и никуда больше не уходят.
- Единственные сетевые обращения — к локальной Ollama и к общей папке.
